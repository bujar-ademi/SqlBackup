# Example configuration

local-job.json illustrates the BackupJob contract using fictional values. It is not an import file or a service configuration file. Configure jobs through the desktop; there is no JSON import workflow.

Create the folders on the correct host and grant the relevant SQL/service identities access. ProgramData may resolve to a different path on your machine. Windows authentication uses the service identity. The example is disabled and has no schedule; no passwords are included. A 30-day retention window still requires preview and confirmation, and dependencies may retain older files.
